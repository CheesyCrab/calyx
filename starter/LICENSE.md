# Starter licensing

The original starter example files in this directory are licensed under MIT.
The Sunny source added to release ZIPs is also distributed under its MIT
option. The complete license text is copied into `LICENSES/MIT.txt` in each
starter ZIP and is available at [`../LICENSES/MIT.txt`](../LICENSES/MIT.txt).

An author's new cart code is independently authored. Before distributing a
cart, the author should choose and record its whole-cart license in
`cart.toml`.
